## More about Write the Docs
Write the Docs is a group, as well as the name of a conference, for those 
interested in Docs as Code. Engineers, writers, project managers, documentation 
enthusiasts, whoever is welcome. The conference can be attended in person or 
remotely, but attending remotely just doesn't quite compare to attending in 
person. Write the Docs consists of a very knowledgeable and passionate group
in various industries and with a wide range of experiences.
